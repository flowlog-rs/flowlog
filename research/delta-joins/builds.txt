# Every binary the study measured, and how to make it: scripts/build.py reads
# this table. Columns are separated by `|`; `#` starts a comment.
#
# A program row compiles a Datalog program with FlowLog:
#   name | path of the .dl file from the repository root
#   name | ctadl:WORKLOAD/PHASE, a CTADL analysis that scripts/ctadl_stage.py
#          staged in $DATA/ctadl (CTADL.md)
#
# A variant row copies another build's generated crate and rewrites its
# src/main.rs, then builds it:
#   name | base build | settings | patches
# Settings are NAME=value environment variables for the patches, separated
# by spaces; a value runs to the next ` NAME=` or the end. Patches are files
# in patches/, applied in order: `.py` files rewrite main.rs in place,
# `.diff` files are applied with patch(1).
#
# Patches find the code they rewrite by the variable names FlowLog
# generates, which hash the plan, so they match the crates the compiler at
# this commit generates and may need updating after the planner changes.
#
# Suffixes: `_p` adds the memory probe (patches/probe.py), and `_pc` adds
# record counters on top (patches/count.py). The three CSPA batch probe
# builds count too but keep the `_p` names that results/ uses.
